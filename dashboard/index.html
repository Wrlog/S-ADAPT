Population PK/PD models for S-ADAPT

Six pharmacokinetic/pharmacodynamic models written for S-ADAPT with the SADAPT-TRAN pre-processor. Each has a study simulated from known parameters and a population fit of that study by Monte Carlo parametric expectation maximisation (MC-PEM), started from deliberately poor initial estimates. This page shows what came back.

These fits were not made with S-ADAPT. S-ADAPT's licence does not allow it to be redistributed, so the fits come from a reference MC-PEM written for the repository, which compiles the same model files. Running the models in S-ADAPT itself is the next step; the run guide says how.

How well the population means were recovered
